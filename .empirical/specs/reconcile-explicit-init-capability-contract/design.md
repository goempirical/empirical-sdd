# Design: Focused Living-Contract Reconciliation

The correction has no runtime surface. One `agent-integrations` delta replaces
three named requirements using the living-specification merge key (requirement
title). Each replacement preserves the existing safety guarantees while
assigning the global and repository-local responsibilities accurately.

No source, generated integration, test, package, context, or public
documentation file changes. Specify validates the delta and capability claim;
the normal Verify, Review, and independent Integrate gates prove structural
validity and merge the replacements transactionally.

Verification searches the resulting capability for the old claims that help
directs normal work to a global `empirical` skill or that the global Init
contract owns tracker and feature routing.
